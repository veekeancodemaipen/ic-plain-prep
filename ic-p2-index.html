การให้คำแนะนำการลงทุน

แนวปฏิบัติเสนอขายผลิตภัณฑ์เสี่ยงสูง — ข้อสอบเชิงสถานการณ์ ออกแนว "ใครทำถูก/ผิด" เก็บคะแนนได้ง่ายถ้าจำหลักได้

สอบ P2 แล้วได้อะไร

  • P1 + P2 = ใบอนุญาต IC Complex 2 — เพิ่มสิทธิ์แนะนำตราสารหนี้และกองทุนรวมที่มีความเสี่ยงสูง/ซับซ้อน
  • เก็บ P3 (อนุพันธ์) เพิ่มอีกหลักสูตรเดียว จะได้ IC Complex 1 แนะนำได้ทุกผลิตภัณฑ์
  • สมัครสอบที่ศูนย์ทดสอบ ATI หรือ AIMC

จุดที่ออกสอบบ่อย (จากข้อสอบตัวอย่าง)

  • สิทธิเลื่อน/งดจ่ายดอกเบี้ยเป็นของ "ผู้ออก" ไม่ใช่ผู้ถือ — หลอกบ่อยที่สุด
  • ตราสารซับซ้อนส่วนใหญ่: อายุไม่แน่นอน · yield สูงกว่า · สภาพคล่องต่ำกว่า ตราสารหนี้ปกติ
  • Convertible / Callable / Puttable bond = ตราสารหนี้ปกติ ไม่ใช่ตราสารซับซ้อน
  • ข้อคำนวณ payoff ของ structured notes — แทนค่าตามเงื่อนไขตรง ๆ ได้คะแนนฟรี
  • การให้คำแนะนำ: ต้องเตือนความเสี่ยงเสมอ แม้ลูกค้ามีประสบการณ์ · ห้ามทำแบบทดสอบแทน · ห้ามเน้นแต่จุดเด่น
Knowledge Base

สรุปเนื้อหา P2

เก็บประเด็นหลักครบ 3 องค์ความรู้ — อิงหนังสือ "ความรู้เกี่ยวกับผลิตภัณฑ์ตลาดทุน: ตราสารที่มีความซับซ้อน (ตราสารหนี้และกองทุนรวม)" ของ SET

องค์ความรู้ 1 · ตราสารหนี้ที่มีความเสี่ยงสูง/ซับซ้อน

🧭 ลักษณะร่วมของตราสารหนี้ซับซ้อน

  • • จ่ายกระแสเงินสด ไม่แน่นอน — ผู้ออก (ไม่ใช่ผู้ถือ) มีสิทธิเลื่อน/งดจ่ายดอกเบี้ยตามข้อกำหนด
  • • อายุไม่ชัดเจน บางกรณีไม่กำหนดอายุ · ลำดับสิทธิรับชำระหนี้ ด้อยกว่า ตราสารหนี้แท้
  • • ผลตอบแทน สูงกว่า ตราสารหนี้ปกติ (ชดเชยความเสี่ยง) · สภาพคล่องตลาดรอง ต่ำ
  • • ⚠️ Callable / Puttable / Convertible bond = ตราสารหนี้ปกติ ไม่นับเป็นตราสารซับซ้อน

🔀 Hybrid Securities & ตราสารเลื่อนจ่ายดอกเบี้ย

  • • คล้ายตราสารทุนแต่ จ่ายดอกเบี้ย (ไม่จ่ายปันผล) · อายุยาว/ไม่แน่นอน
  • • ลำดับสิทธิด้อยกว่า เจ้าหนี้บุริมสิทธิและเจ้าหนี้สามัญ → yield สูงกว่าปกติ
  • • สิทธิเลื่อนจ่ายดอกเบี้ยเป็นของ ผู้ออกฝ่ายเดียว — ทำตามเงื่อนไขครบ = ไม่ถือว่าผิดนัด
  • • มักมีข้อกำหนด: เลื่อนจ่ายดอกเบี้ยแล้ว ห้ามจ่ายปันผลผู้ถือหุ้น (คุ้มครองผู้ลงทุน)

🏦 ตราสาร Basel III & Perpetual Bond

  • • Basel III: ออกโดย ธนาคารพาณิชย์เท่านั้น เป็นหุ้นกู้ ด้อยสิทธิ นับเป็นเงินกองทุน
  • • มีข้อกำหนด แปลงเป็นหุ้นสามัญหรือตัดหนี้สูญ เมื่อเกิด trigger events · สภาพคล่องต่ำมาก
  • • Perpetual: ผู้ออกเป็นได้ทั้งบริษัททั่วไป/สถาบันการเงิน · ชำระเงินต้นครั้งเดียวเมื่อเลิกกิจการ แต่ดอกเบี้ยจ่ายตามสัญญา
  • • มักให้สิทธิผู้ออก ไถ่ถอนก่อนกำหนด เมื่อพ้นระยะเวลาที่ระบุในหนังสือชี้ชวน

🧮 หุ้นกู้อนุพันธ์ (Structured Notes)

  • • จ่ายผลตอบแทนส่วนเพิ่ม แปรผันตามตัวแปรอ้างอิง · คุ้มครองเงินต้น ทั้งหมดหรือบางส่วน ก็ได้
  • • ELN: ราคาหุ้น > strike → เงินต้น+ดอกเบี้ย · ≤ strike → รับหุ้นที่ราคา strike
  • • อ้างอิงดอกเบี้ย: แทนค่าสูตร payoff ตรง ๆ เช่น ต้น + ต้น×max(1%, 10%−MLR)
  • • อ้างอิง FX: USD แข็งกว่า strike → ได้เงินบาทคืน · อ่อนกว่า/เท่ากับ → ได้ USD = หน้าตั๋ว/strike

📉 ตราสารหนี้ที่มีความเสี่ยงสูง (High Yield)

  • • คือตราสารหนี้ที่ อันดับเครดิตต่ำกว่า BBB− (non-investment grade) หรือ ไม่มีการจัดอันดับ (unrated) — ไม่ใช่ต่ำกว่า B−
  • • เสี่ยงผิดนัดสูงกว่าปกติ แม้ผู้ออกจะเป็นบริษัทใหญ่ → ห้ามบอกลูกค้าว่า "ไม่กระทบเงินต้น"

องค์ความรู้ 2 · กองทุนรวมที่มีความเสี่ยงสูง/ซับซ้อน

📊 นิยาม & กองทุน High Yield

  • • ลงทุนตราสารหนี้ต่ำกว่าระดับลงทุนได้/unrated เกินกว่า 60% ของ NAV (เลขเกณฑ์ออกสอบ!)
  • • จ่ายผลตอบแทนตาม สูตร/เงื่อนไขที่เข้าใจยาก · ไม่จำกัดอัตราส่วนลงทุน (กระจุกตัวได้) · ใช้อนุพันธ์เพื่อสร้างผลตอบแทน
  • • ลงทุน Junk bond ได้ · ผลตอบแทนมาในรูปดอกเบี้ย · เสี่ยงผิดนัดสูงกว่ากองทุนทั่วไป
  • • เหมาะกับสถาบัน/รายใหญ่ที่เข้าใจและรับความเสี่ยงได้ · real return เป็นบวก เหมาะภาวะดอกเบี้ยต่ำ

🎯 กองทุนรวม Complex Return

  • • ผลตอบแทนขึ้นกับเงื่อนไขของอนุพันธ์/ตราสารที่มีอนุพันธ์แฝง ที่กองทุนลงทุน
  • • Asian Option = จ่ายตามส่วนต่าง strike กับ ราคาเฉลี่ย ของสินทรัพย์อ้างอิงในช่วงเวลา
  • • Binary Option = จ่าย คงที่ เมื่อสัญญามีมูลค่า / ไม่ได้อะไรเลยเมื่อไม่มีมูลค่า — ข้อสอบชอบสลับนิยามสองตัวนี้
  • • โครงสร้างทั่วไป: ตราสารหนี้ ~96.5% + ออปชัน ~3.5% แล้วจ่ายผลตอบแทนเป็นขั้นตามราคาอ้างอิง

🛢️ กองทุนโภคภัณฑ์ (ทอง/น้ำมัน ผ่านอนุพันธ์)

  • • ผลตอบแทน ไม่เท่ากับ spot — สัญญามีวันหมดอายุ + ต้นทุนเปลี่ยนสัญญา (rollover)
  • • Basis Risk = ราคาฟิวเจอร์สเคลื่อนไม่สัมพันธ์กับราคา spot
  • • Rollover Risk สูง ในการถือยาว จากต้นทุนธุรกรรม + ภาวะ Contango / Backwardation
  • • ปัจจัยอุปทานเช่น เชลล์ออยล์ กระทบราคากองทุนน้ำมัน · กอง ETF น้ำมันมีผลตอบแทนจากส่วนต่างราคา + ปันผล (ถ้ามี)

♟️ Hedge Fund & กองทุนใช้อนุพันธ์ซับซ้อน

  • • Hedge Fund: ไม่จำกัดอัตราส่วนลงทุน เสี่ยงสูง · short sell และกู้ยืมเงินมาลงทุนได้ · กำกับดูแลน้อยกว่า
  • • ปัจจุบันเสนอขายเฉพาะ ผู้ลงทุนรายใหญ่พิเศษ (UHNW) เท่านั้น
  • • กลยุทธ์: Tactical Trading = เก็งกำไรการเคลื่อนไหวราคา · Relative Value = ซื้อขายหลักทรัพย์ที่สัมพันธ์กัน ≥ 2 ตัว
  • • Hedging ต้องทำสัญญา ไม่เกินมูลค่าความเสี่ยงที่มี — เกิน = Over hedge (เพิ่มความเสี่ยงแทน)

องค์ความรู้ 3 · การให้คำแนะนำการลงทุน

✅ หลักการเสนอขายผลิตภัณฑ์เสี่ยงสูง

  • • ต้องคัดเลือกบุคลากรที่ เข้าใจผลิตภัณฑ์ ที่จะเสนอขาย
  • • เตือนความเสี่ยงทุกครั้ง — แม้ลูกค้ามีประสบการณ์ลงทุนมา 20 ปี
  • • เสนอขาย Basel III ต้องอธิบาย worst case scenario ก่อนลงทุน
  • • ลูกค้าไม่ผ่านแบบทดสอบความรู้ → ไม่ให้ลงทุน (ห้ามทำแบบทดสอบแทนเด็ดขาด)
  • • ให้ข้อมูลครบทั้งจุดเด่นจุดด้อย แม้กระทบยอดขาย — ห้ามเน้นแต่จุดเด่นจนลูกค้าเข้าใจผิดว่าคุ้มครองเงินต้น

⚖️ การผิดนัดชำระหนี้ & ผู้แทนผู้ถือหุ้นกู้

  • • ถือเป็นการผิดนัด: ไม่รักษาอัตราส่วนการเงินตามข้อตกลง (เช่น D/E) · นำทรัพย์สินไปค้ำประกันเจ้าหนี้อื่นทั้งที่ตกลงว่าจะไม่ก่อภาระหลักประกัน
  • • หุ้นกู้ที่มี ผู้แทนผู้ถือหุ้นกู้ — การใช้สิทธิเรียกร้องต้องทำ ผ่านผู้แทนฯ ตามกฎหมาย
