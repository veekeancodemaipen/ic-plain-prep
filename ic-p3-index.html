สอบ P3 แล้วได้อะไร

  • P1 + P3 = IC Complex 3 — เพิ่มสิทธิ์แนะนำสัญญาซื้อขายล่วงหน้า (futures · options · swap)
  • P1 + P2 + P3 = IC Complex 1 — แนะนำได้ทุกผลิตภัณฑ์ในตลาดทุน จุดสูงสุดของสาย IC
  • สมัครสอบที่ศูนย์ทดสอบ ATI หรือ AIMC · ค่าสอบ 950 บาท

จุดที่ออกสอบบ่อย (จากข้อสอบตัวอย่าง)

  • ฟิวเจอร์ส vs ฟอร์เวิร์ด: Exchange/มาตรฐาน/สำนักหักบัญชี/Mark to Market vs OTC/customized/เสี่ยงคู่สัญญาสูง
  • ออปชันเป็นสัญญาแบบ "สิทธิเรียกร้อง" — ฟอร์เวิร์ด/ฟิวเจอร์ส/สวอป เป็นพันธะผูกพัน
  • คำนวณ payoff Long/Short + margin call เติมกลับถึง "หลักประกันขั้นต้น" เสมอ
  • วันครบกำหนด: ราคาฟิวเจอร์สบรรจบกับ spot → เบสิส = 0
  • สินค้าใน TFEX เกือบทั้งหมด ชำระเงินสด (เป็นเงินบาท) — ยกเว้นยาง RSS3 ส่งมอบจริง
Knowledge Base

สรุปเนื้อหา P3

เก็บประเด็นหลักครบ 5 องค์ความรู้ — อิงหนังสือ "ความรู้เกี่ยวกับผลิตภัณฑ์ตลาดทุน: ตราสารที่มีความซับซ้อน (สัญญาซื้อขายล่วงหน้า)" ของ SET

🧭 ภาพรวมอนุพันธ์

  • • สัญญาตกลงซื้อขายสินค้าอ้างอิง ณ เวลาในอนาคต ด้วยจำนวน/ราคาที่กำหนดวันนี้ · อายุจำกัด · ใช้เงินลงทุนน้อยกว่าซื้อสินค้าตรง (leverage)
  • • สินค้าอ้างอิงเป็นได้ทั้ง สินค้ามีตัวตน และ ตัวแปร (ดัชนี, ดอกเบี้ย) — ตัวแปรไม่ต้องส่งมอบจริง ใช้ Cash Settlement
  • • ประเภท: พันธะผูกพัน = ฟอร์เวิร์ด ฟิวเจอร์ส สวอป · สิทธิเรียกร้อง (Contingent Claim) = ออปชัน
  • • ประโยชน์: บริหารความเสี่ยงราคา · ทำกำไรจากการเปลี่ยนแปลงราคา · สะท้อนราคาในอนาคต (price discovery) — ไม่ใช่แหล่งระดมทุน
  • • ผู้เล่น: Hedger (ถือของจริง+เปิดสถานะตรงข้าม เช่น ถือหุ้น SET50 → Short SET50 Futures) · Speculator · Arbitrageur · Market Maker

⚡ ฟิวเจอร์ส vs ฟอร์เวิร์ด (ออกสอบทุกชุด)

  • • ฟิวเจอร์ส: ซื้อขายใน Exchange · สัญญามาตรฐาน (contract specification) · สำนักหักบัญชีเป็นคู่สัญญา → เสี่ยงผิดนัดต่ำ · Mark to Market ทุกวัน · สภาพคล่องสูง · มี Daily Price Limit ตามประกาศตลาด
  • • ฟอร์เวิร์ด: ตกลงกันเองใน OTC · customized · เสี่ยงคู่สัญญาสูงกว่า · ชำระครั้งเดียววันครบกำหนด
  • • เปลี่ยนมือในตลาดรองได้โดย ไม่ต้องขอความยินยอม จากคู่สัญญาเดิม

🧮 Payoff & การกำหนดราคาฟิวเจอร์ส

  • • กำไร/ขาดทุน = (ราคาขาย − ราคาซื้อ) × ขนาดสัญญา × จำนวนสัญญา · Short ได้กำไรเมื่อราคาลง / Long ได้กำไรเมื่อราคาขึ้น
  • • ราคายุติธรรม ณ วันทำสัญญา → มูลค่าสุทธิของสัญญา = ศูนย์ ทั้งสองฝ่าย
  • • Cost of Carry: F = S + C − Y (C = ต้นทุนถือครอง/เก็บรักษา/ขนส่ง · Y = ประโยชน์เช่นเงินปันผล) — เงินปันผลเป็นปัจจัยของฟิวเจอร์ส "หุ้น" ไม่ใช่โภคภัณฑ์
  • • Convergence: ณ วันส่งมอบ ราคาฟิวเจอร์ส = ราคา spot · อายุสัญญาต่างกัน → ราคาต่างกัน

📐 เบสิส & สเปรด

  • • Basis = F − S (ผลต่าง ไม่ใช่ผลรวม) → วันครบกำหนด = 0 · F ขึ้นมากกว่า S → เบสิส "กว้างขึ้น" · ปันผลเพิ่ม/ต้นทุน C ลด → F ลด → เบสิส "แคบลง"
  • • Calendar Spread = ผลต่างราคาฟิวเจอร์ส 2 สัญญา สินค้าเดียวกันต่างเดือน (F2 − F1) · ต้องมี ≥ 2 สถานะ (ซื้อหนึ่ง + ขายหนึ่ง)
  • • Bull Spread = คาดว่าเดือนส่งมอบ "ไกล" จะขึ้นแรงกว่าเดือนใกล้ · เบสิสกว้างขึ้นต่อเนื่อง → ซื้อเดือนไกล + ขายเดือนใกล้
  • • การลงทุนสเปรด/เบสิส ไม่สนทิศทางราคา — สนการเปลี่ยนแปลงที่ไม่เท่ากันของแต่ละเดือน/ตลาด

🎯 กลยุทธ์: Hedge · เก็งกำไร · Arbitrage

  • • เป้าหมาย Hedge = คุมความเสี่ยงให้อยู่ระดับที่ยอมรับได้ (ไม่ใช่ผลตอบแทนสูงสุด) · ถือหุ้นกลัวลง → Short Single Stock Futures
  • • Partial Hedge = ป้องกันเพียงบางส่วนของมูลค่าพอร์ต · Beta = ความเสี่ยงที่เป็นระบบ
  • • Directional Bet / สเปรด = เก็งกำไร (Speculation) · กำไรปราศจากความเสี่ยง = Arbitrage
  • • คาดทองลง → Short Gold Futures · คาดหุ้นขึ้น → Long Stock Futures

🎫 ออปชัน (Options)

  • • Call = สิทธิ "ซื้อ" / Put = สิทธิ "ขาย" สินค้าอ้างอิง ณ ราคาใช้สิทธิ (Exercise price) — ผู้ซื้อจ่ายพรีเมียมให้ผู้ขายออปชันประเภทเดียวกัน
  • • เมื่อ Spot > Strike: ผู้ซื้อ Call ได้ประโยชน์ (ITM, intrinsic > 0) · ผู้ซื้อ Put เสียประโยชน์ (intrinsic = 0)
  • • ปัจจัยดันราคา Call ขึ้น: ราคาหุ้น↑ · อายุคงเหลือ↑ · ความผันผวน↑ · เงินปันผล↓ (สัมพันธ์เชิงลบ)
  • • มูลค่าออปชันขึ้นกับ strike, ความผันผวน, เวลา ฯลฯ — ไม่เกี่ยวกับระดับการยอมรับความเสี่ยงของผู้ลงทุน

🏦 กลไกตลาด TFEX: หลักประกัน & ส่งมอบ

  • • วาง หลักประกันขั้นต้น (IM) ก่อนเทรด · Mark to Market ทุกสิ้นวัน · ต่ำกว่า หลักประกันขั้นต่ำ (MM) → ถูก Call Margin เติมกลับถึง IM
  • • ตัวอย่าง: Long 1 สัญญา @100 (1,000 หุ้น) IM 10,000/MM 7,000 → สิ้นวัน 96 → ขาดทุน 4,000 เหลือ 6,000 < MM → เติม 4,000
  • • ปิดฐานะ = เปิดสัญญาทิศทางตรงข้าม "สินค้าเดียวกัน + เดือนส่งมอบเดียวกัน" (Long GFZ18 → Short GFZ18)
  • • Cash Settlement = ชำระส่วนต่างเงินสด · ยาง RSS3 = Physical Delivery ส่งมอบจริง ณ ที่ TFEX กำหนด

📦 สินค้า & สัญลักษณ์ + แนวปฏิบัติการขาย

  • • S50 = SET50 Index Futures · S50C/S50P = SET50 Call/Put Options · GF = Gold Futures · เดือน: H=มี.ค. M=มิ.ย. U=ก.ย. Z=ธ.ค. (GFM18 = ส่งมอบ มิ.ย. 2018)
  • • SET50/Stock/Gold/Currency Futures ชำระ เงินสดเป็นเงินบาท · ราคาชำระ Stock Futures = ค่าเฉลี่ยถ่วงน้ำหนัก 15 นาทีสุดท้าย + ณ เวลาปิด (ทศนิยม 2 ตำแหน่ง)
  • • แนวปฏิบัติ: ส่งคำสั่ง ตามลำดับก่อน-หลัง ไม่ใช่ตามความสำคัญลูกค้า · KYC ต้องมีหลักฐานแหล่งที่มารายได้เสมอ · ลูกค้าบางประเภทได้รับ ยกเว้น suitability ตามเกณฑ์ ก.ล.ต.
