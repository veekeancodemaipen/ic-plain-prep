# IC Plain (P1) — คลังความรู้เตรียมสอบ

เว็บไซต์เตรียมสอบ **ผู้แนะนำการลงทุนตราสารทั่วไป (Investment Consultant — Paper 1)**
ดีไซน์ Minimalist Dark Mode สไตล์ Fintech · ไฟล์ HTML เดียว ไม่ต้องติดตั้งอะไร

## เนื้อหา
- **คลังความรู้** 3 หมวด (การเงิน/การลงทุน · กฎระเบียบ-จรรยาบรรณ · ผลิตภัณฑ์ตลาดทุน)
- **สูตรคำนวณ** ที่ต้องจำ + **กลยุทธ์สอบ**
- **ข้อสอบเก่า 100 ข้อ** แบบอินเทอร์แอกทีฟ — เลือกคำตอบแล้วเฉลยทันที พร้อมคำอธิบาย กรองตามหมวด และนับคะแนน

## โครงสร้าง
- `ic-plain-index.html` — ทั้งเว็บอยู่ในไฟล์เดียว (Tailwind CDN + ฟอนต์ Prompt)
- `vercel.json` — rewrite ให้เปิดเว็บได้ที่ root URL

> เอกสารนี้จัดทำเพื่อการเตรียมสอบเท่านั้น โปรดตรวจสอบหลักเกณฑ์ฉบับล่าสุดจาก SET และ ก.ล.ต.
