เทคนิคจำ (Keyword)

  • ราคาตราสารหนี้ ↔ ดอกเบี้ย = ผกผัน เสมอ (ออกแน่)
  • ผกผัน: ดอกขึ้นราคาลง / ดอกลงราคาขึ้น · ยาว/คูปองต่ำ = อ่อนไหวมาก
  • ความเสี่ยงกระจายได้ = ไม่เป็นระบบ (เฉพาะตัว) · กระจายไม่ได้ = เป็นระบบ (β)
  • BBB− ขึ้นไป = Investment Grade
  • กองทุนความเสี่ยง 1 (ตลาดเงิน) → 8 (สินทรัพย์ทางเลือก)
  • RMF: ลงทุนถึง 55 ปี + ลงทุนมาแล้ว ≥ 5 ปี · SSF: ถือ ≥ 10 ปี
  • Suitability ทบทวนทุก ≥ 2 ปี

โฟกัสจุดออกสอบบ่อย

  • อ่านโจทย์หา keyword "ผกผัน / มากที่สุด / ไม่ใช่ / ยกเว้น" ให้ดี
  • ข้อจรรยาบรรณมักมีตัวเลือก "เห็นแก่ตัว / รับประกัน / ทำแทนลูกค้า" = มักเป็นข้อที่ผิด
  • หมวดจรรยาบรรณ: ผลประโยชน์ลูกค้ามาก่อน · ห้ามรับประกันผลตอบแทน · ห้าม churning · ห้ามเทรดแทนโดยพลการ
  • เก็บหมวด 2 ให้แม่นที่สุด — เป็นความจำ ทำคะแนนได้ง่าย และเป็นเกณฑ์ตัดผ่าน
  • ข้อคำนวณตราสารหนี้/กองทุน เก็บไว้ทำตอนท้าย ถ้าจำสูตรแม่นได้ฟรี

อัปเดตเนื้อหา (ของใหม่ที่ออกสอบ)

เนื้อหาที่ตลาดหลักทรัพย์ฯ ปรับปรุง/เพิ่มเติม (จากเอกสาร update P1) — เน้นจุดที่ตำราเก่ายังไม่มี และมักออกสอบในข้อใหม่

🏛️ ตลาดรอง & สถานที่ซื้อขาย

  • • ศูนย์ซื้อขายทางการ (organized exchange): SET (ทุนชำระแล้วหลัง IPO ≥ 300 ลบ.) · mai (≥ 20 ลบ.) · LiVEx (สำหรับ SME/Startup เปิด 31 มี.ค. 2565)
  • • TFEX — ศูนย์ซื้อขายอนุพันธ์ (กำกับโดย ก.ล.ต.)
  • • ศูนย์ซื้อขายสินทรัพย์ดิจิทัล — ต้องได้ใบอนุญาตจาก ก.ล.ต.
  • • OTC = ตกลงกันเองนอกศูนย์ (เช่น NASDAQ ในสหรัฐฯ ส่วน NYSE เป็น organized exchange)

💻 ระบบซื้อขายของ SET (พัฒนาการ)

  • • เคาะกระดาน (2518) → ASSET (2534) → ARMS (2551) → SET CONNECT/Cinnober (2555)
  • • ปัจจุบัน: SET CONNECT ใหม่ ร่วมกับ Nasdaq (8 พ.ค. 2566)
  • • เผยแพร่ราคา Bid/Offer จาก 5 → 10 ระดับ · Timestamp ระดับ nanosecond
  • • ฟังก์ชันใหม่: Self-match Prevention, Pre-trade Risk Management

🚀 LiVEx (เจาะลึก)

  • • 3 แนวคิด: Light-Touch Supervision · Investor Protection · Information-Based
  • • เปิดเฉพาะผู้ลงทุนที่รับความเสี่ยงได้ (สถาบัน/VC/PE · ผู้เชี่ยวชาญ · ผู้เกี่ยวข้องบริษัท · รายใหญ่พิเศษ)
  • • ซื้อขายแบบ Auction วันละ 1 รอบ 9.30–11.00 น. · ชำระแบบ Gross ในวัน T
  • • ห้าม short sell, DMA, Algorithmic Trading · ไม่มี ceiling/floor & circuit breaker
  • • Silent period 3 ปี (ทยอยขาย 20% เมื่อครบ 1 ปี)

🪙 สินทรัพย์ดิจิทัล (Digital Asset)

  • • ตาม พ.ร.ก. สินทรัพย์ดิจิทัล พ.ศ. 2561 = คริปโทเคอร์เรนซี + โทเคนดิจิทัล
  • • โทเคนดิจิทัล 2 แบบ: investment token (สิทธิร่วมลงทุน) · utility token (สิทธิได้สินค้า/บริการ)
  • • เสนอขายโทเคนผ่าน ICO portal ที่ ก.ล.ต. เห็นชอบ
  • • ICO ≠ IPO: ผู้ถือโทเคนอาจไม่ใช่เจ้าของ/เจ้าหนี้บริษัท — มีสิทธิตาม white paper
  • • คริปโทฯ ยังไม่ใช่ legal tender (มีแค่ El Salvador รับ Bitcoin)

🌱 การลงทุนอย่างยั่งยืน (ESG)

  • • Sustainable Investment พิจารณา 3 มิติ: E สิ่งแวดล้อม · S สังคม · G บรรษัทภิบาล
  • • เป้าหมายคือ บริหารความเสี่ยง + สร้างโอกาสผลตอบแทน ไม่ใช่การกุศล/CSR
  • • ช่วยประเมินมูลค่าสินทรัพย์ที่จับต้องไม่ได้ (intangible asset) เช่น แบรนด์ ค่าความนิยม
  • • G ครอบคลุมการต่อต้านทุจริต และการเสียภาษีอย่างถูกต้องโปร่งใส

🌏 DR vs DRx (ตราสารแสดงสิทธิหลักทรัพย์ต่างประเทศ)

  • • DRx = fractional DR ซื้อขายเป็นเศษหน่วย/จำนวนเงินได้ (ขั้นต่ำ 0.0001 DRx)
  • • DRx: ชำระ Real-time · เวลาตามตลาดต่างประเทศ · Dynamic Price Band · สัญลักษณ์ลงท้าย X · ผ่านแอป Streaming
  • • DR: ชำระ T+2 · เวลา SET 9.30–17.00 · ceiling/floor 30% · ขั้นต่ำ 1 DR
  • • ผู้ออก DR/DRx ไม่ใช่เจ้าของหลักทรัพย์ แต่ถือหลักทรัพย์ต่างประเทศแทนผู้ลงทุนไทย

⚖️ การซื้อขายที่ไม่เป็นธรรม (Market Misconduct)

ตามข้อบังคับ SET — False Market

  • • Wash sales — ผู้ซื้อ-ผู้ขายเป็นคนเดียวกัน
  • • Pool — สมรู้ร่วมคิดเพื่อประโยชน์ร่วม
  • • Series of transaction — ซื้อขายต่อเนื่องเอื้อฐานะ
  • • Cornering — กักหลักทรัพย์ให้คนอื่นส่งมอบไม่ได้
  • • False dissemination — แพร่ข่าวที่ยังไม่แจ้งตลาด

ตาม พ.ร.บ.หลักทรัพย์ฯ 2535 (4 ลักษณะ)

  • • Misstatement ข่าว/ข้อความเท็จ (ม.240)
  • • Insider trading ใช้ข้อมูลภายใน (ม.242–244)
  • • Front running ตัดหน้าคำสั่งลูกค้า (ม.244/1–2)
  • • Market manipulation ปั่นหุ้น (ม.244/3–7)
